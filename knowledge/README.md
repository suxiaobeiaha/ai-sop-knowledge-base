# knowledge/ — 知识源(唯一真相源)

这里才是你的知识资产本体;Dify 只是它的检索索引,可随时从本目录重建。

## 主线地图

- **10-工作**(职场主线):支付业务 / 技术支持 / 研发产品 / 项目管理 / 软考 / 跨境清结算
  → 让工作更轻松,沉淀面试素材,做职业跳板

> 个人成长、副业相关内容为私有知识,不入本仓库(本地保留在 `20-成长/`、`30-副业/`)。

## 组织规则

- 每条笔记按 [_templates/笔记模板.md](_templates/笔记模板.md) 写
- 敏感内容脱敏后入库(见 ../docs/05 §4)
- 新子域预期条目 ≥ 5 条才建;不足先放域根目录

## 三步蒸馏

1. **写**:做完一件事 / 踩完一个坑 → 用模板写一条 md
2. **审**:自查质量规范(见 ../docs/05 §4)
3. **入库**:导入 Dify 对应数据集 → 检索验收 → `git commit`
