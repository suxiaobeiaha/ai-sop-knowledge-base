# 10-工作 — 职场主线

目标:把"技术支持 + 支付行业 + 项目管理"的方法论蒸馏成可复用资产,
让工作更轻松,同时作为职业跳板(面试 / 晋升)的素材库。

## 子域

| 目录 | 内容 |
|---|---|
| [11-支付业务](11-支付业务/) | 行业知识:通道、清算、合规、风控、接口 |
| [12-技术支持](12-技术支持/) | 排障方法论、沟通、SOP、效率(核心域) |
| [13-研发产品](13-研发产品/) | 需求、联调、工具、技术栈经验 |
| [14-项目管理](14-项目管理/) | 决策思路、复盘、干系人管理 |
| [15-软考](15-软考/) | 备考蒸馏(考证支撑职业路线) |

## 蒸馏心法

- 你不是研发但常干研发/产品的活 → 这正是差异化价值,把"跨角色经验"记下来
- 每条复盘按「背景 → 动作 → 结果」写,天然就是面试 STAR 案例
- 涉猎广是你的现状,知识库让广度变成结构化资产;检索复用会把广度慢慢磨成深度
