# 11-支付业务

三方支付行业知识:业务模式、通道/清算、合规监管、风控、商户、接口联调。

## 首批候选

- [ ] 公司业务模式与产品线梳理(聚合支付 / 收单 / 分账等)
- [ ] 清算结算流程:交易 → 清分 → 结算 链路笔记
- [ ] 常见交易异常场景与处理(支付失败 / 掉单 / 退款 / 争议)
- [ ] 乐刷(leshua)接口签名方案:MD5/SM3、字段排除规则、`"lepos"+key+data` 变体(从 e:\code 脚本复盘)
- [ ] TLV 终端数据解码方法(hex → tag+length+value)
- [ ] 合规要点:反洗钱、商户入网审核、二清风险

> 含商户号 / 密钥的内容必须脱敏(`<MCH_ID>` 占位),见 [docs/05](../../../docs/05-知识库设计.md) §4
